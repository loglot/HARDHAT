# HARDHAT
a graphical [HAT](https://github.com/FEZModding/HAT) installer


# Usage
download the [latest zip](https://github.com/loglot/HARDHAT/releases/latest), run HARDHAT.sh, follow the app 

THE HAT INSTALLER DEPENDS ON [MONO](https://www.mono-project.com/), be sure to install that before installing HAT 

# Running from Source;
clone this repository using git clone

run npm start

resolve any errors if they show up
